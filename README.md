# localization-ru-yog-sothoths-yard

Русская локализация **Yog-Sothoth's Yard**, версия **1.2**. Проект [Anigor Games](https://anigor-games.ru/).

Python-установщик для Windows 10/11 и **Steam build 24329824**. Переведены все 23 318 непустых текстовых записей. Визуальная проверка продолжается: две особо длинные реплики могут выходить за пределы диалогового окна.

## Что требуется

- Установленная оригинальная игра поддерживаемой сборки.
- Python 3.10 или новее. Подойдут команды `py` или `python`, если Python добавлен в PATH.
- Права записи в папку игры. Игра должна быть закрыта.

Библиотеки через pip, PowerShell и интернет для установки не нужны. Если Python отсутствует, используйте отдельный выпуск с установщиком EXE.

## Установка

Скачайте ZIP-архив [репозитория на GitHub](https://github.com/Master-anigor/localization-ru-yog-sothoths-yard) и распакуйте его целиком либо клонируйте репозиторий:

```console
git clone https://github.com/Master-anigor/localization-ru-yog-sothoths-yard.git
cd localization-ru-yog-sothoths-yard
```

Папка `patch` должна находиться рядом с `patch_game.py`.

Откройте терминал в папке с `patch_game.py` и выполните:

```console
py -3 patch_game.py install
```

Скрипт ищет игру рядом с собой и в библиотеках Steam. Если подходящая папка не найдена однозначно, он попросит путь. Можно указать его сразу:

```console
py -3 patch_game.py install --game "D:\Games\SteamLibrary\steamapps\common\Yog-Sothoth's Yard"
```

Выберите папку с `Yog-Sothoth's Yard.exe`. Если команда `py` отсутствует, замените `py -3` на `python`.

После успешной установки выберите **English** в настройках языка игры. Русский заменяет английскую локализацию; корейский временно недоступен. Китайский и японский сохранены. Скрипт не нужен во время игры.

## Проверка и удаление перевода

```console
py -3 patch_game.py verify --game "D:\Games\SteamLibrary\steamapps\common\Yog-Sothoth's Yard"
py -3 patch_game.py restore --game "D:\Games\SteamLibrary\steamapps\common\Yog-Sothoth's Yard"
```

Оригиналы сохраняются в `YogSothothYard_RU_Backup` внутри игры. **Не удаляйте эту папку до восстановления оригиналов.** Резервные копии совместимы с выпуском на PowerShell. Повторные установка и восстановление безопасны.

Если установлен более ранний русификатор, сначала восстановите оригиналы его установщиком. После обновления игры в Steam этот патч может перестать подходить: неизвестные игровые файлы скрипт изменять не будет. Сохранения игрока не изменяются.

Для автоматического запуска добавьте `--non-interactive`; в этом режиме `--game` обязателен и автоматический поиск отключён.

## Как устроена установка

`patch/patch_manifest.json` описывает две разрешённые цели: `resources.assets` и `sharedassets0.assets`. `patch/payload.bin` содержит данные бинарных изменений. Полные игровые ресурсы в репозиторий не входят.

Установщик проверяет SHA-256 исходных файлов, данные патча, границы каждой операции и готовый результат. Сначала собираются оба новых файла и сохраняются оригиналы; затем ресурсы заменяются через Windows ReplaceFile. При ошибке замены выполняется откат. При запущенной игре установка и восстановление запрещены.

## Проверки разработчика

`tests/test_patch_game.py` запускает изолированные проверки на временных игровых файлах. Укажите **копию оригинальных ресурсов** поддерживаемой сборки; тесты не ищут игру в Steam и не изменяют источник. Все созданные файлы остаются внутри явно выбранной папки `--work`.

```console
py -3 tests/test_patch_game.py --source "D:\OriginalGameFixture" --work "D:\PatchChecks"
```

В исходной папке должны находиться `Yog-Sothoth's Yard_Data/resources.assets` и `Yog-Sothoth's Yard_Data/sharedassets0.assets`. Для тестов не требуется настоящий EXE игры.
